# Andrew Mathews — Personal Website

A responsive personal portfolio website for Andrew Mathews, a developer, student, and technology enthusiast based in Dubai, UAE.

The site showcases Andrew's interests in web development, artificial intelligence, robotics, cybersecurity, and STEM projects.

## Live Website

Visit the deployed site: [andrewmkbuilds.github.io/my-personal-site](https://andrewmkbuilds.github.io/my-personal-site/)

## Features

- Responsive layout for desktop, tablet, and mobile screens
- Hero section with profile introduction and calls to action
- About section with background and interests
- Featured projects section
- Skills and technologies section
- Learning and blog section
- Contact section with email call-to-action
- Smooth scrolling navigation
- Dark blue and gold visual theme
- No frameworks or build tools required

## Built With

- HTML5
- CSS3
- GitHub Pages

## Running Locally

Because this is a static website, no installation or build step is required.

1. Clone the repository:

   ```bash
   git clone https://github.com/andrewmkbuilds/my-personal-site.git
   ```

2. Open the project directory:

   ```bash
   cd my-personal-site
   ```

3. Open `index.html` in a browser.

For a better local development experience, use a local server such as the VS Code Live Server extension or Python's built-in server:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000` in your browser.

## Customization

To personalize the site:

- Update the text and section content in `index.html`.
- Replace `profile.jpg` with a preferred profile image.
- Add real project URLs to the project cards.
- Replace the placeholder email address in the contact section.
- Adjust colors, spacing, typography, and responsive behavior in `style.css`.

## Deployment

This repository is configured for GitHub Pages. To deploy or update the site:

1. Push changes to the `main` branch.
2. In the repository settings, open **Pages**.
3. Select **Deploy from a branch**.
4. Choose the `main` branch and the root folder.
5. Save the configuration.

GitHub Pages will publish the static site at the repository's Pages URL.
